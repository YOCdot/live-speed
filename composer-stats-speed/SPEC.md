# composer-stats-speed 规格说明

在 ZCode 输入框右下角状态区显示当前模型生成速度（纯数字），悬停显示速度标签与数值（中文 `Tokens / 秒`，英文 `Tokens / Second`）。

## 1. 用户可见行为

- 芯片：`gauge` 图标 + 数字 `N`
- 悬停：`zh-CN` 为 `Tokens / 秒 · N`，其他语言为 `Tokens / Second · N`
- 数值格式：一律四舍五入取整，不显示小数
- 没有任何实时值、会话平均和历史值的会话：不显示芯片
- 语言：激活时读 `env.get().locale`，并订阅 `env.onDidChange`；以 `zh` 开头的 locale 用中文，其他一律英文

## 2. 数据来源

| 数据 | 接口 | 授权 | 可靠度 |
| --- | --- | --- | --- |
| 实时速度 | `models.onDidGenerate`（`outputTokensPerSecond`、`outputTokens`、`timeToFirstTokenMs`、`model`、`phase`） | 无 | 唯一权威来源 |
| 重启回填 | 插件数据目录 `speed-last.json`（自身写入） | 无 | 上次的最终值 |
| 会话平均 | `sessions.readRows` 的 `turnHeader`（所有轮次 `outputTokens / modelDurationMs` 加权） | `sessions.read` | 本机 1.4.0 上常失败 |
| 界面语言 | `env.get().locale`、`env.onDidChange` | 无 | — |

## 3. 取值优先级

1. 正在运行（streaming 事件，且属于当前轮）→ 实时速度
2. 本步结束（final 事件，非磁盘回填）→ 本步平均（该次生成的最终速度）
3. 历史会话（无实时值）→ 会话平均（所有 `turnHeader` 的 `outputTokens / modelDurationMs` 加权）
4. 行数据不可用 → 最新一轮平均
5. 仍无值 → 磁盘回填的该会话上次值（不借用其他会话的值）
6. 都没有 → 不显示

## 4. 持久化

- 路径：`${ZCODE_PLUGIN_DATA}/speed-last.json`
- 内容：`{ v: 2, sessions: { <sessionId>: { tps, ttft, tokens, model, at } } }`，每个会话只保存自己的值，最多保留 50 个最近会话
- 版本：只读取 `v === 2`；旧 v1 文件（可能含跨会话回填的污染值）直接忽略，由后续写入覆盖为 v2
- 只按会话回填：读取某会话的记录时不会把它复制到其他会话；新会话没有自己的记录时不显示速度
- 写入时机：收到 `phase === "final"` 事件后延迟 3 秒合并写入；插件停用时同步落盘（宿主可能不等异步写完成）
- 读取时机：`activate` 时先回填再渲染，使已有记录的会话在重启后立即有值
- 周期重写：每 30 秒对当前可见会话强制重写一次槽位，宿主清空值后能自动恢复

## 5. 状态与降级

| 场景 | 行为 |
| --- | --- |
| `readRows` 失败 | 标记降级，按 4 秒起指数退避重试（上限 60 秒）；仅在该会话可见时重试，重新可见时立即重试；不熔断 |
| 行流断开 | 保留实时值，只标记降级；该会话可见时 5 秒后重订阅 |
| 未授权 `sessions.read` | 仅失去会话平均，实时与持久化回填仍工作 |
| 实时事件缺失 | 使用会话平均或该会话的回填值，绝不写入空值 |
| `reset` 事件 | 算到临时状态，有轮次或平均才替换，保留实时值 |
| 新会话无数据 | 不写入槽位，也不从其他会话复制值 |

## 6. 验收标准

1. 正在运行时芯片显示 streaming 实时速度；一次生成结束（`phase === "final"`）后显示该次的本步平均（冒烟）。
2. 插件实例销毁后重新激活，行数据不可用时芯片立即显示上次值（冒烟 `speed(持久化)`）；行数据可用时显示会话平均。
3. `readRows` 抛错时，实时值仍然显示（冒烟 `speed(降级)`）。
4. 行流报错后，实时值仍然显示（冒烟 `speed(降级)`）。
5. 事件所属会话不在可见列表时也会写入（冒烟）。
6. 任何一次写入都不含空文本（冒烟 `不闪`）。
7. 芯片文本为整数 `169`、`23`、`7`（四舍五入）；悬停中文为 `Tokens / 秒 · 169`、`Tokens / 秒 · 23`、`Tokens / 秒 · 7`，英文为 `Tokens / Second · …`（单测）；运行时切换语言后立即更新（冒烟 `speed(i18n)`）。
8. 读行失败时，重启后仍能用该会话的持久化值回填（冒烟 `speed(快照)`）。
9. 新会话没有自己的数据时不写入槽位，不拿其他会话的速度回填（冒烟 `speed(不回填)`）。
10. 读行失败后，会话重新可见时自动补读并显示（冒烟 `turn(重试)` 同款机制；速度插件同路径）。

## 7. 已知边界

- 宿主未向扩展暴露缓存命中率，因此本插件不显示该指标。
- `models.onDidGenerate` 只在生成期间发出；静态会话只能依赖会话平均或该会话自己的回填值。
- 回填值是"上一次生成"的速度；有行数据时会话平均优先于回填值。新会话没有记录时不显示，宁可缺一枚芯片也不显示别的会话的数字。
- 宿主对不在信任范围的会话会拒绝读行，插件靠退避重试与会话重新可见时的立即补读恢复，不能绕过宿主授权。
- 非中文 locale 一律回退英文；本地持久化只存数字与模型名，不存语言相关文案。
- 悬停纯文本，不使用 emoji；芯片文字上限 40 字符。
- 扩展 API 版本约束：`engines.zcode ^1.4.0`。
