# composer-stats-step 规格说明

在 ZCode 输入框右下角状态区显示当前轮内的模型步数，悬停显示步数标签与数值（中文 `步数`，英文 `Step`）。

## 1. 用户可见行为

- 芯片：`layers` 图标 + 数字 `N`
- 悬停：`zh-CN` 为 `步数 · N`，其他语言为 `Step · N`
- 未授权：芯片显示 `步数·未授权` / `Steps · no grant`
- 当前轮没有任何可统计的响应：不显示芯片，也不写入空值
- 语言：激活时读 `env.get().locale`，并订阅 `env.onDidChange`；以 `zh` 开头的 locale 用中文，其他一律英文

## 2. 数据来源

| 数据 | 接口 | 授权 |
| --- | --- | --- |
| 轮次边界与状态 | `sessions.onDidChangeRows`、`sessions.readRows` 的 `turnHeader` 行 | `sessions.read` |
| 步数与工具调用 | 同一行日志的 `assistantText`、`reasoning`、`toolCall` 行 | `sessions.read` |
| 模型名（悬停备用） | `context.get` | 无 |
| 界面语言 | `env.get().locale`、`env.onDidChange` | 无 |

## 3. 口径

- **当前轮**：`rowId` 最大的 `turnHeader`；换轮时清空上一轮的响应与工具集合。
- **步数**：当前轮内 `assistantResponseId` 去重后的数量，即模型请求数。
- **空轮处理**：轮状态为 `running` 且尚无响应时按 1 计（模型已开始请求）；轮已结束且无响应则为 0，不显示。
- **工具调用次数**：当前轮内 `toolCallId` 去重后的数量。
- **迟到行**：`turnId` 与当前轮不一致的增量行直接忽略。

## 4. 状态与降级

| 场景 | 行为 |
| --- | --- |
| 用户拒绝 `sessions.read` | 未授权态 |
| `readRows` 抛错 | 保留已有统计，标记降级；会话可见时按 4 秒起指数退避重试（上限 60 秒），重新可见时立即重试 |
| 行流断开 | 保留最后一次结果，只标记降级；会话可见时 5 秒后重订阅 |
| `reset` 事件 | 算到临时状态，存在 `turnId` 才替换 |
| `stale` 事件 | 后台重读，成功且非空才替换 |
| 宿主重启/插件更新 | 先读本地快照（`${ZCODE_PLUGIN_DATA}/step-state.json`）并立即写槽位，再读行覆盖；每 30 秒强制重写一次 |
| 无数据 | 不写入槽位 |

## 5. 验收标准

1. 同一 `assistantResponseId` 的多行只计 1 步（单测）。
2. 新轮开始时步数重置为 1，工具计数归零（单测）。
3. 流式 upsert 不改变步数（单测）。
4. 旧 `turnId` 的迟到行不影响当前轮（单测）。
5. 悬停文本为 `步数 · 7` / `Step · 1`（单测逐字）；运行时切换语言后立即更新（冒烟 `step(i18n)`）。
6. 任何一次写入都不含空文本。
7. 插件重新激活且 `readRows` 失败时，芯片立即显示快照里的最后值（冒烟用例 `step(快照)`）。
8. 首次读行失败后，会话重新可见时自动补读并显示（与轮次插件共用同一套重试逻辑，冒烟用例 `turn(重试)`）。

## 6. 已知边界

- 与轮次插件共享同一宿主限制：宿主只允许读取当前信任范围的会话，新会话创建瞬间、刚切换的会话可能返回 `forbidden: Target is outside the trusted scope`，部分版本还会在输出校验时抛 `ZodError`；插件按可见性退避重试并重订阅，切回会话后能自愈，不能绕过宿主授权。
- 不做"总步数"统计：宿主内部虽有 `historyRoundCount`，但该字段不通过扩展 API 暴露，且语义是"轮内步数"，与本插件口径一致，故无需依赖。
- 悬停纯文本，不使用 emoji；芯片文字上限 40 字符。
- 快照只保存数字；悬停文案按当前语言重建，所以切换语言不会残留旧文案。
- 扩展 API 版本约束：`engines.zcode ^1.4.0`。
